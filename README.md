# BSNLink
Delivers approved BSN store orders, reports player count and sends PlaceholderAPI stats to the website.
Needs PlaceholderAPI, Java 11+, Spigot/Paper 1.16+.
Build: `mvn package` (or push this folder to GitHub and run the "Build BSNLink" action). Setup: see ../README-AR.md.
Commands: `/bsnlink reload`, `/bsnlink test` (permission `bsnlink.admin`).
